# Changelog

## [1.0.4] - 2026-11-04

### Changed
- Uses less memory: the game loads when you open it, not when KOReader
  starts, so it no longer takes memory or startup time while unplayed.

## [1.0.3] - 2026-11-03

### Changed
- Picks up game-common 1.11.0: the shared on-screen keyboard (where used)
  gives every key the same letter size, and the no-repeat history helper.

## [1.0.2] - 2026-11-02

### Changed
- Picks up game-common 1.10.0: the shared Tools → Games menu also lists
  the games' new "· multiplayer" entries under Party & quiz.

## [1.0.1] - 2026-11-02

### Changed
- Listed under **Tools → Games**, grouped by category, instead of its own
  entry in the Tools menu (game-common 1.9.1).

## [1.0.0] - 2026-10-30

### Added
- First release: twelve decks to read aloud — Would you rather, Never have I ever, Who's most likely to, Get to know you, Hot seat (three questions for one player), Famous dinner, Dilemmas, Absurd debates, This or that, Story starters, Guess who, Time machine.
- 3437 French / 3303 English family cards; opt-in Adults mode adds 409 spicier cards per language (never explicit).
- Deck multi-select, random order without repeats, Previous/Next, optional player names with turn display, "New game" once the deck is exhausted, saved game in progress.
- Interface in English, French, Spanish and German; cards in French or English.
